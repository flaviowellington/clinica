# Glossary

| Term | Definition | Evidence |
|---|---|---|
| Clinipay | Braço financeiro do Clinicorp: conta digital, maquininha, boleto, Pix, antecipação de recebíveis | [doc SRC-007] |
| Alerta de Retorno | Lembrete para chamar o paciente de volta após um intervalo (manutenção, revisão) | [doc SRC-001] |
| Anamnese | Questionário de saúde do paciente, personalizável, com assinatura eletrônica | [doc SRC-001] |
| Odontograma | Mapa dos dentes onde se marcam condições e procedimentos | [doc SRC-002] |
| Orçamento | Proposta de tratamento com procedimentos e valores, gerada do plano de tratamento | [doc SRC-001] |
| Portal de Assinaturas | Local onde o paciente assina orçamentos, contratos e termos | [doc SRC-002] |
| CRC | Central de Relacionamento com o Cliente (plano Premium) | [doc SRC-002] |
| Régua de cobrança | Sequência automática de lembretes de pagamento | [doc SRC-002] |
| TISS | Padrão da ANS para troca de informações entre prestadores e operadoras de planos de saúde (guias, lotes XML) | [doc SRC-012] |
| NFS-e | Nota Fiscal de Serviço eletrônica; padrão nacional obrigatório desde 2026 | [doc SRC-010] [doc SRC-011] |
| Clini.me | App do Paciente, com check-in por QR Code | [doc SRC-002] |
| Orçamento / Tratamento | Mesmo registro: nasce como orçamento (IsEstimate) "Em Aberto" e vira tratamento cobrável ao ser aprovado | [net EV-008, EV-013] |
| Lançamento de Tratamento | Linha no financeiro do paciente criada pela aprovação do orçamento | [net EV-013] |
| Em espera / Check-in | Status da consulta que marca a chegada do paciente e inicia a contagem de espera | [net EV-016] |
| Controle Protético | Kanban de trabalhos de laboratório: Pré-envio → Envio/Em laboratório → Retorno à clínica → Agendamento do paciente → Instalado | [obs EV-018] |
| Smartboard | Motor de quadros kanban interno, usado no Controle Protético e nas Indicações | [net EV-018, EV-010] |
| FDI | Numeração internacional de dentes (11–18, 21–28, 31–38, 41–48) usada no odontograma | [obs EV-007] |
| A realizar / Executado / Existente | Legenda do odontograma para procedimentos planejados, feitos e preexistentes | [obs EV-011] |
